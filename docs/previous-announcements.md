## New UST Rankings!

- **Announcement date:** July 1, 2025
- **Commit date:** July 3, 2025
- **Commit:** [`13467c1f20f15a8985f834cd23ea8dad0ed0bf71`](https://github.com/ust-archive/ust-rankings/commit/13467c1f20f15a8985f834cd23ea8dad0ed0bf71)
- **Original path:** `components/component/new-release-banner.tsx`
- **Source:** `git show 13467c1f20f15a8985f834cd23ea8dad0ed0bf71:components/component/new-release-banner.tsx`

Hi there! We have just released a new version of UST Rankings with some exciting features:

- **New Ranking Algorithm.** We have improved the ranking algorithm to provide more accurate and reliable rankings.
- **New Data Source: SFQ.** We have introduced a new ranking data source, the official Student Feedback Questionnaire (SFQ). We hope that this will provide a more comprehensive view of the instructors and courses.
- **Support Course Filtering.** We have supported to filter the courses by their attributes, such as showing only the courses that are offered in the current term, or only the common core courses.

We are also planning to add more features in the future, but we need your opinion!

- **Adding Review.** We are considering adding a feature that allows users to leave short reviews for instructors and courses. Different from ust.space, we plan to only allow short reviews of a few sentences, so to grab a quick overview of the instructor or course. Perhaps, we would support emoji reaction just like what we have here.

We hope that you will enjoy the new features and improvements. As always, if you have any feedback or suggestions, please feel free to contact us.

UST Rankings Team. July 1, 2025.

Hi there! We have just released a new version of UST Rankings with some long-lasting bug fixes. They used to cause the following issues:

- **Invisible Rankings.** Some rankings were not visible via search to users. We have fixed this issue. Now, all instructors who have taught / courses which have been offered for at least one term are now visible.
- **Invisible Data Sources.** Some data source, either ust.space or SFQ, was not visible to users in some rankings. We have fixed this issue.

As said in the previous announcement, we are looking forward to improve UST Rankings by supporting users to leave a short review for courses and instructors. We are working on this feature and it will be available soon.

As always, if you have any feedback or suggestions, please feel free to contact us at [ust-rankings@flandia.dev](mailto:ust-rankings@flandia.dev).

UST Rankings Team. June 26, 2026.
